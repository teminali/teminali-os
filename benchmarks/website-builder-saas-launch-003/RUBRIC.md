# Evaluation Rubric (Benchmark 003)

| :--- | :--- | :--- |
| **1. Semantic Architecture** | 20 | Header, nav, main, footer landmarks; valid heading tree; semantic form controls. |

| **Total** | **100** | Strictly automated oracle verification. |
